=====================================
 PORTFOLIO WEBSITE - SETUP GUIDE
=====================================

📁 FILES INCLUDED:
------------------
1. index.html     - Home page
2. about.html     - About page
3. projects.html  - Projects page
4. contact.html   - Contact page
5. style.css      - All styling
6. script.js      - All JavaScript

🚀 HOW TO RUN:
----------------
1. Open VS Code
2. Install "Live Server" extension
3. Right-click on index.html
4. Click "Open with Live Server"
5. The website will open in your browser

🔗 NAVIGATION:
---------------
- All pages are linked via the navigation bar
- Click on Home, About, Projects, Contact to switch pages

🎨 FEATURES:
-------------
✅ Dark/Light Mode toggle
✅ Responsive design
✅ Contact form with validation
✅ Active page highlighting in nav

⚠️ NOTE:
---------
- Profile images use placeholder images (via.placeholder.com)
- Replace with your own images if needed
- No backend required - works with just HTML, CSS, JS

Enjoy! 🎉
